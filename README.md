# Salimpo 山海學習聚落

寧埔國小課程、教案、教材、文史、展演與競賽成果，以及評鑑和原民會訪視資料的圖文網站。

網站：<https://laierin615.github.io/salimpo-school-resources/>

## 內容

- 12個可點選的3D聚落地點：9個主島入口（含左岸望向女人島的「古謠樹 · Radiw」，連到 Radiw 古謠×未來式與古調的現代新衣兩個網站）；兩座小外島：連到海岸阿美語競賽訓練場的「族語挑戰島」，和以阿美族女人島口傳為靈感、連到膽曼 Sa'opo 歌謠採譜網站的「女人島」；以及給老師用的第12站「村辦公室」。教材工坊、文史資料館、訪視評鑑會客室併站後，位置 3、9、10 的房子留成空房子（點不到），以後新增的站可以住進去：在 `index.html` 加一列站牌，再把位置加進 `village.js` 的 `spots`。
- 聚落可以拖曳轉動與俯仰、平移；Ctrl／⌘＋滾輪、觸控板或雙指可以縮放，也有＋、−、復位按鈕。站牌號碼平常收起來，滑過、拖曳或點選時才浮現。
- 主選單用聚落站名：學校與部落、山海探索站、教材書屋、成果廣場、資料服務站、會客室。文史資料館收在教材書屋裡，原民會訪視與實驗教育評鑑收在會客室裡；舊的 `learning.html` 轉到山海探索站（課程架構的網址轉到課程架構屋）。
- 每一站一個族語詞（如 niyaro' 部落、dateng 野菜），首頁問候 Nga'ay ho!、頁尾 Aray!；全部取自 tatokem 已驗證詞庫，驗證腳本會再核對一次。
- 手繪Salimpo主Logo，保留原圖的山、太陽、彩色字母與筆觸，用於首頁、子頁、頁尾及網站圖示。
- 17個頁面、62筆資料入口、31個教案閱讀主題、25項展演及比賽成果；24項評鑑指標皆附學校做法與關聯頁面。
- 25卷完整閱讀內容，共1298頁PDF圖像及章節式文字、表格、照片。
- 114原始課程架構圖、115・116螺旋式課程設計、四個合作計畫。
- 「我們怎麼學」：113、114學年度10堂課的學習步驟卡，從開始動手、卡關重來到完成作品；照片中的姓名與臉已打上馬賽克，不連到原始 Padlet 留言板。
- 山海探索站依主題整合：8個主題（山林與食農、服飾與工藝、族語與故事、部落與歷史、樂舞與音樂、建築與家屋、祭典與生活、海洋與科學），打開一個主題依序是影音資料（課程影片、課程照片）、課程架構、教材（對應的課程單元）、學生作品（活動紀錄、學習步驟卡、Padlet 學習歷程原板），最後是教案。課程架構依主題裡各課的內容產生：主題 → 低中高年段 → 每一課與學習重點；學習重點從各課學習目標濃縮，存在 `data.js` 每一課的 `points`，主題的學習脈絡在 `lessonTopicFlows`；沒有教案對應或也教到別的主題的課程單元列在 `lessonTopicUnits`。新增的課會自動排進架構，還沒寫 `points` 時先顯示學習目標的前三條。每一課的頁面也是同樣順序；舊的教材工坊網址轉到主題總覽。總覽下方連到全校課程地圖（課程架構屋）與學習步驟卡。
- 教材書屋四個書架：Masao 老師的文史資料（7篇完整文史，另有文史資料館15個主題入口）、我們的繪本（《Itira i 'alo.》在小溪裡、《Misolap ci Awos to dateng》Awos 的野菜探險記）、出的書（國泰圓夢計畫第一冊、第二冊）、族語教材（山林中的動物、下雨天、颱風天、一年級生的對話）。每本都能在山海閱讀室翻閱，繪本與族語教材另附 PDF 下載。首頁循環六組族語與中文短句。
- 會客室：入口頁兩扇門，分「原民會訪視」與「實驗教育評鑑」兩頁，門下列出可以直接前往的面向。原民會訪視為10月30日10:00、四大面向12項、20分鐘學校簡報22張（可左右切換、放大看）、三份官方表件、八場研習、經費彙整與29份核銷原件目錄；實驗教育評鑑為七大面向24項。每一項的佐證依計畫與文件、課程與教案、學習歷程與成果、部落與夥伴四類列出，另附四大文化領域與31個教案的對照、山海課程與部定領域統整表。
- 村辦公室：老師的工作小屋，輸入通關密碼才開門。裡面有打卡（只是效果，時間只留在那台裝置）、每週共備紀錄、115學年度各課程各年段教案紀錄、海岸阿美語詞資料庫與 Padlet 學校帳號。頂端列、每頁頁尾和聚落第11站都能進入。
- 星空 fo'is：把三美九向、四大文化領域、教案、學習步驟卡、成果、合作計畫與文史畫成一片可以互動的星空，像 Obsidian 的關聯圖。原民會訪視指標 1-2 的四大文化領域（永續發展、文藝美學、生命哲學、民族社會）是四個星座的軸心，排在四角；九向、課與相連的星依資料歸到星座，橫跨兩個星座的星（例如生活美、山海人文、山海成果展）放在星座之間，跟哪個星座都沒有連線的星（例如足球隊）放在中間。連線只取 `data.js` 已有的對應，另加老師指定的對應（`stars.js` 的 `CONFIRMED`：四個成果主題、科展與閱讀等成果、四個合作計畫、三個課程單元、十字繡與農耕步驟卡、五篇文史，依學校九向的內涵連到三美、九向或文化領域），不自己推測。整頁就是全螢幕星空：從頂端列、每頁頁尾或夜晚的聚落天空按「星空」進來，舊畫面退後暗下、星空從中央展開，星星由中央往外亮起；左上角 Logo 回首頁，右上放大縮小，瀏覽器支援時還有全螢幕按鈕（連網址列都蓋掉），左下是清單與依種類篩選；可以拖曳、搜尋，點星星看介紹再前往那一頁。

## 發布與維護

GitHub Pages只發布 `dist/`。推送 `main` 分支會由 `.github/workflows/pages.yml` 驗證及自動發布。

```sh
node tools/verify-site.mjs
python3 -m http.server 8766 --directory dist
```

- 頁面及版面：`dist/*.html`、CSS、JS。
- 資料索引：`dist/data.js`。
- 完整閱讀：`dist/books/`。
- 主Logo：`dist/media/brand/salimpo-logo.png`。
- 3D場景與互動：`dist/village.js`、`dist/village-ui.js`。
- 學習步驟卡：`dist/journeys.*`，資料在 `data.js` 的 `journeys`，圖片在 `dist/media/journeys/`。
- 教材書屋：`dist/library.*`；書架在 `data.js` 的 `library`，由 PDF 轉頁面圖、複製下載用 PDF 到 `dist/media/library/`。新增一本書：轉好 `books/<id>.json` 與 `media/<id>/`，在 `books` 與 `library.shelves` 各加一筆（`pdfs` 要寫檔案大小）。
- 會客室：`dist/reception.html`、`dist/room.js`、`dist/room.css`；佐證在 `data.js` 各訪視項目與評鑑指標的 `evidence`，教案的文化領域對照在 `curriculum115.lessonDirections`。
- 附件：`dist/attachments/`。
- 村辦公室：`dist/office.html`、`dist/office.js`、`dist/office.css`；加密後的連結 `dist/office-data.js` 由 `tools/build-office.mjs` 產生，不要手動改。
- 星空：`dist/stars.html`、`dist/stars.js`、`dist/stars.css`；星星與連線在瀏覽器裡由 `data.js` 算出，資料更新後星空跟著變，不用另外維護。四個星座的軸心在 `stars.js` 的 `AXES`；`data.js` 沒寫、但老師確認過要連的對應加在 `CONFIRMED`。換頁轉場寫在 `stars.css`（瀏覽器的跨頁轉場），星星亮起的進場在 `stars.js`。

所有站內連結使用相對路徑，支援GitHub Pages專案子目錄。網站供持有網址者免登入瀏覽；只有村辦公室要輸入通關密碼。

### 村辦公室的連結與密碼

連結原文在 `.runtime/office-links.json`，密碼在 `.runtime/office-password.txt` 第一行；兩個檔都列在 `.gitignore`，不會上傳。網站上只有加密後的 `dist/office-data.js`（PBKDF2-SHA256 60萬次＋AES-256-GCM）。改了連結或換密碼後，重新加密，再驗證、推送：

```sh
node tools/build-office.mjs                    # 讀 .runtime/office-password.txt 第一行
OFFICE_PASSWORD='新密碼' node tools/build-office.mjs
node tools/build-office.mjs --check            # 確認現有 office-data.js 能用這組密碼解開
```

全校老師共用一組密碼，至少8個字元。密碼只擋住網站上的入口；文件能不能打開，仍由 Google 文件與 Padlet 的共用設定決定。
